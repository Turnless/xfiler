## Pattern system
- `/master-learn` discovers patterns from the code and writes them to `.claude/patterns/draft.md`
- `/master-modify` changes, adds, or removes a pattern (also via the draft)
- `/master-review` verifies the draft, promotes it into grand-master, and audits the code
- Never edit the grand-master directly. Only `/master-review` does that.
